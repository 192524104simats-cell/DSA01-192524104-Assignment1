## Project Description
This project focuses on designing, implementing, and validating the fare logic of a City Metro Smart-Card System using C++.

## Software Requirements
- Operating System: Windows 11
- Programming Language: C++
- Compiler: g++ 16.2.0
- Standard: C++17
- Editor: Visual Studio Code

## Folder Structure
The project contains separate folders for Tasks 01 to 12. Each folder is intended to contain its C++ source code, input files, and output screenshots.

## Compilation and Execution
Open the MSYS2 UCRT64 terminal and navigate to the project folder.

Example for Task 01:

```bash
g++ -std=c++17 -Wall -Wextra Task01/task01.cpp -o Task01/task01.exe
./Task01/task01.exe
```

Repeat the compilation and execution process for each task using its corresponding source file.
